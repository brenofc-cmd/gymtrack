# Atribuição dos vídeos de exercícios

Todos os arquivos `wger-*.m4v` desta pasta são cópias otimizadas para celular
de vídeos distribuídos pela [wger](https://wger.de/).

- Autor do vídeo: **Goulart**
- Fonte: **wger**
- Licença do objeto de vídeo: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- Alteração feita pelo GymTrack: conversão do arquivo original para M4V,
  redução para os primeiros oito segundos e otimização para reprodução móvel.

O número depois de `wger-` identifica o exercício na fonte. A página com os
autores, licença, imagens e vídeos de cada item está disponível em:

`https://wger.de/api/v2/exerciseinfo/{ID}/`

Exemplo: `wger-73-barbell-bench-press.m4v` corresponde a
`https://wger.de/api/v2/exerciseinfo/73/`.

Esta atribuição acompanha os créditos exibidos diretamente sobre cada vídeo na
interface do GymTrack. As fotos de início e fim usadas como fallback permanecem
provenientes do free-exercise-db sob Unlicense, conforme documentado nas
migrations de mídia do projeto.
