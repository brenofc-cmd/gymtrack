# Imagens de exercícios

As imagens desta pasta vêm do projeto público [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), disponibilizado sob a licença [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE).

O script `npm run sync:exercise-images` baixa novamente a primeira imagem de cada movimento usado pelo catálogo do GymTrack.
